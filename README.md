# /posicionamento — skill de posicionamento na era da IA (método April Dunford)

Skill para o Claude que funciona como um **agente-entrevistador**: ele conversa com você (dono de negócio, de solopreneur a
empresa com times separados) e aplica ao **seu** negócio o método de posicionamento de April Dunford — o framework base de
*Obviously Awesome* + as 4 coisas-chave da era de IA apresentadas no #mtpcon London 2026.

No fim da conversa você recebe um **documento de posicionamento** preenchido:

- Declaração de posicionamento (cliente de melhor encaixe, alternativa competitiva, categoria, valor diferenciado, capacidades)
- Ponto de vista sobre o futuro do mercado, ancorado no que você faz de verdade
- Roadmap de posicionamento em etapas (hoje → visão)
- Ponte de maturidade (onde o cliente está vs. para onde a mudança vai)
- Plano para operacionalizar o entendimento do cliente

## As 9 fases
0. Contexto rápido do negócio · 1. Alternativas competitivas · 2. Capacidades distintas · 3. Valor diferenciado ·
4. Clientes de melhor encaixe · 5. Categoria de mercado · 6. Ponto de vista sobre o futuro · 7. Roadmap em etapas ·
8. Modelo de maturidade · 9. Operacionalizando o entendimento do cliente

## Como instalar

**Claude Code** — copie a pasta `posicionamento` para `~/.claude/skills/`:

```bash
git clone https://github.com/grupoideapps/posicionamento-ia-skill.git
cp -r posicionamento-ia-skill/posicionamento ~/.claude/skills/
```

Depois é só pedir: *"usa a skill posicionamento pra revisar o posicionamento do meu negócio"* ou digitar `/posicionamento`.

**Claude.ai (app/web)** — compacte a pasta `posicionamento` em `.zip` e envie em *Configurações → Capacidades → Skills*.
